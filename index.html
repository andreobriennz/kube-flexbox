Collapse / Accordion

  • What is kube-flexbox?

    kube-flexbox is a CSS framework that combines Kube 6.5 with Flexbox-Grid, replacing Kube's traditional grid system with a modern flexbox alternative.

  • How do I customise it?

    Edit src/kube/src/_scss/_components.scss to comment out any components you don't need, then run npm run build to regenerate the dist files.

  • Does it require JavaScript?

    The CSS works without JavaScript. Interactive components (tabs, collapse, modal, dropdown, messages) require jQuery and dist/kube-flexbox.js.
